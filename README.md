# 🧠 Memory Card Game

A simple, colorful, and interactive memory matching game built with Vanilla JavaScript, HTML & CSS. Test your memory by finding all the matching emoji pairs!

[**🔗 Play the Live Game Here**](https://flip-game-adk.netlify.app/) 

## 🎮 How to Play

1. The game board consists of 20 face-down cards (10 unique pairs of emojis).
2. Click on any card to flip it over and reveal the emoji hidden underneath.
3. Click on a second card to try and find a match.
4. If the emojis match, the cards remain face up.
5. If they don't match, the cards will flip back over after a short delay.
6. Match all 10 pairs to win the game! A celebratory popup will appear once you succeed.

## ✨ Features

* **Dynamic Emoji Pool:** Each game randomly selects 10 emojis from a large pool of over 100 options, ensuring a unique experience every time you play.
* **Smooth Animations:** 3D flip animations powered by CSS transitions provide a satisfying tactile feel.
* **Responsive Design:** A clean, colorful UI that centers the game board and looks great on any screen size.
* **Win State & Restart:** Automatically detects when the game is won and offers a convenient "Play Again" button to shuffle a new board.

## 🛠️ Technologies Used

* **HTML5:** Structuring the game container and popup modal.
* **CSS3:** Styling, flexbox/grid layouts, gradients, and 3D flip animations (`transform-style: preserve-3d`).
* **JavaScript (ES6):** Game logic, DOM manipulation, event listening, and array shuffling.

## 📁 File Structure

* `index.html` - The main HTML document containing the game board structure and win popup.
* `style.css` - The stylesheet defining the colorful background, card flip animations, and layout.
* `script.js` - The game logic handling emoji selection, shuffling, card flipping, match checking, and win conditions.
